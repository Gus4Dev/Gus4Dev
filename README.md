### 💻 Sobre Mim

Estudante de Tecnologia da Informação com foco em **Desenvolvimento de Software**, direcionando meus estudos para **Backend** e com objetivo de evoluir posteriormente para **Full Stack**. Possuo um perfil dedicado à construção de bases sólidas, unindo raciocínio lógico, organização e vontade constante de aprender.

Atualmente estou construindo minha base por meio de estudos, projetos práticos e preparação para o mercado de trabalho, buscando transformar conhecimento em experiência.

* 🎓 **Formação:** Ensino Médio Técnico Integrado em Logística.
* 💻 **Tecnologia:** Estudante de TI pelo **PROA/SENAC**, em preparação para ingressar no mercado de tecnologia.
* ⚙️ **Desenvolvimento:** Atualmente desenvolvendo conhecimentos em **JavaScript, Python, HTML, CSS e Lógica de Programação**.
* 🌐 **Web Development:** Praticando desenvolvimento web através de projetos e exercícios utilizando HTML, CSS e JavaScript.
* 🧠 **Programação:** Construindo fundamentos de lógica, resolução de problemas, estruturas condicionais, repetição e organização de código.
* 🚀 **Objetivo:** Trabalhar com **Desenvolvimento de Software, com foco em Backend**, evoluindo posteriormente para Full Stack.
* 🎓 **Próximo objetivo acadêmico:** Cursar **Análise e Desenvolvimento de Sistemas (ADS)**.
